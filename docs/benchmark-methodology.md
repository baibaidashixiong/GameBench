# Benchmark 测试方法

## 模式

- Reproducible：固定种子、固定规模、Affinity、预热、重复次数和严格结果校验。
- Realistic：更大规模、动态任务强度和更接近引擎帧中的调度分布，但仍记录完整配置。

## 单次运行

1. 校验配置并生成确定性输入。
2. 执行预热阶段，不采样。
3. 记录重复样本的帧时间和线程时间。
4. 验证工作负载输出校验值。
5. 保存原始样本、配置、硬件和环境信息。

## 公平性

- 所有架构使用相同算法、数据规模和编译选项。
- 不以厂商名称选择特殊代码路径。
- 拓扑不确定时不做性能推断。
- Vulkan No-Submit 与 GPU-backed 模式分开报告，GPU 时间不混入 CPU 综合分数。
- Synthetic 与真实引擎结果分开评分。

## 统计

报告中提供均值、中位数、P95、P99、P99.9 和最大值。异常值保留在原始数据中；任何过滤规则必须显式记录配置和影响。
